CDN代理转换

// 将GitHub raw URL转换为CDN URL
原始URL: https://raw.githubusercontent.com/user/repo/branch/file.md
CDN URL: https://cdn.jsdelivr.net/gh/user/repo@branch/file.md

// 这样可以避免CORS跨域限制，并获得CDN加速
