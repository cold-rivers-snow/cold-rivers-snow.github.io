# 动态内容加载功能说明

## 问题背景

博客的"每日资讯"页面使用了远程内容（Markdown文件和RSS订阅），但Hugo在构建时会缓存这些远程资源。这导致：

1. **安全资讯**显示的是构建时缓存的历史内容，而不是最新的当天内容
2. **博客资讯**和**每日动态**也受到同样的缓存影响
3. 只有重新构建并部署博客，才能更新这些内容

## 解决方案

实现了**客户端动态加载**方案，通过JavaScript在用户浏览器中实时获取最新内容。

### 实现内容

#### 1. JavaScript库 (`assets/js/dynamic-content-loader.js`)

提供了三个核心函数：

- **`loadRemoteMarkdown(elementId, url)`** - 动态加载远程Markdown文件
  - 添加时间戳防止浏览器缓存
  - 支持marked.js解析，也提供了基础的Markdown转HTML功能
  - 显示加载时间和来源信息

- **`loadRssFeed(elementId, rssUrl, count)`** - 动态加载RSS订阅
  - 使用rss2json API转换RSS为JSON
  - 显示指定数量的最新文章
  - 包含标题、链接和发布时间

- **`loadRssFeedDaily(elementId, rssUrl, count)`** - 动态加载今日RSS内容
  - 过滤只显示当天发布的文章
  - 如果当天没有新文章，不显示任何内容
  - 适合"每日动态"场景

#### 2. 新的Hugo Shortcodes

- **`remotemd_dynamic.html`** - 替代原来的 `remotemd`
- **`embedrss_dynamic.html`** - 替代原来的 `embedrss`
- **`embedrssdaily_dynamic.html`** - 替代原来的 `embedrssdaily`

这些shortcode会：
1. 加载必要的JavaScript库
2. 创建容器元素
3. 在页面加载时自动调用相应的加载函数

#### 3. 更新的公告页面

`/content/page/announcement/index.md` 已更新为使用动态版本的shortcode：

```markdown
## 安全资讯

{{< remotemd_dynamic "https://raw.githubusercontent.com/Vu1nT0tal/yarb/main/today.md" >}}

## 博客资讯

{{< embedrss_dynamic "https://www.ruanyifeng.com/blog/atom.xml" >}}
{{< embedrss_dynamic "https://coolshell.cn/feed" 10 >}}
{{< embedrss_dynamic "https://ainews.liduos.com/rss.xml" >}}

## 每日动态

{{< embedrssdaily_dynamic "https://www.infoq.cn/feed" >}}
```

## 主要优势

### ✅ 实时更新
- 用户每次访问页面都会获取最新内容
- 无需重新构建和部署博客

### ✅ 防缓存机制
- 添加时间戳参数防止浏览器缓存
- 确保始终获取最新数据

### ✅ 用户体验
- 显示加载状态提示
- 清晰的错误提示
- 显示内容更新时间

### ✅ 兼容性好
- 不依赖外部Markdown解析库（有基础实现）
- 如果有marked.js则使用更好的解析效果
- 使用标准的Fetch API

## 使用方法

### 在任何页面中使用动态加载

#### 加载远程Markdown文件

```markdown
{{< remotemd_dynamic "https://example.com/content.md" >}}
```

#### 加载RSS订阅（显示5条）

```markdown
{{< embedrss_dynamic "https://example.com/feed.xml" >}}
```

#### 加载RSS订阅（显示10条）

```markdown
{{< embedrss_dynamic "https://example.com/feed.xml" 10 >}}
```

#### 只显示今日发布的RSS内容

```markdown
{{< embedrssdaily_dynamic "https://example.com/feed.xml" >}}
```

## 注意事项

1. **CORS限制**：某些网站可能会限制跨域访问，导致无法直接获取内容
   - RSS订阅使用了rss2json API来绕过CORS限制
   - 如果Markdown文件有CORS限制，需要使用代理或CDN

2. **网络依赖**：内容加载依赖用户的网络连接
   - 如果用户网络较慢，内容加载可能需要时间
   - 会显示"正在加载..."提示

3. **API限制**：rss2json API有请求限制
   - 免费版每天有请求次数限制
   - 如果流量大，可能需要考虑其他方案或自建RSS代理
