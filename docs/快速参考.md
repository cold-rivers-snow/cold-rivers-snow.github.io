## 💡 使用方法

### 在Markdown中使用

```markdown
## 加载远程Markdown
{{< remotemd_dynamic "https://raw.githubusercontent.com/user/repo/branch/file.md" >}}

## 加载RSS订阅（默认5条）
{{< embedrss_dynamic "https://example.com/feed.xml" >}}

## 加载RSS订阅（10条）
{{< embedrss_dynamic "https://example.com/feed.xml" 10 >}}

## 只显示今日发布内容
{{< embedrssdaily_dynamic "https://example.com/feed.xml" >}}
```

## 🔧 核心技术

### 1. GitHub CDN代理
```javascript
原始: https://raw.githubusercontent.com/user/repo/branch/file.md
转换: https://cdn.jsdelivr.net/gh/user/repo@branch/file.md
```

### 2. 超时控制（10秒）
```javascript
const controller = new AbortController();
setTimeout(() => controller.abort(), 10000);
```

### 3. 多URL备选
```javascript
const urls = [convertGitHubToCDN(url), url];
for (let tryUrl of urls) {
    try { /* 尝试加载 */ } 
    catch { /* 继续下一个 */ }
}
```

## 🐛 调试

### 查看错误
1. 按F12打开浏览器开发者工具
2. 切换到Console标签
3. 查看红色错误信息

### 常见问题

**Q: 内容仍然无法加载？**
A: 
1. 检查网络连接
2. 确认源地址可访问
3. 查看浏览器控制台错误
4. 点击重试按钮

**Q: RSS加载很慢？**
A: 
- 正常，因为需要通过api.rss2json.com转换
- 已设置10秒超时
- 如果超时会显示错误信息

**Q: 想添加新的RSS源？**
A: 编辑 `/content/page/announcement/index.md`
```markdown
{{< embedrss_dynamic "新的RSS地址" >}}
```

## 📊 API限制

### rss2json.com 免费版
- 每天 10,000 次请求
- 每小时 500 次请求

如果超过限制，考虑：
- 使用服务端缓存
- 自建RSS代理
- 升级付费版
